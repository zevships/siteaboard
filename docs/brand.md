# SiteAboard 名称与传播

确定名称：**SiteAboard**；中文名：**站舱**；目录与拟议命令名：`siteaboard`。

Site 指网站，Aboard 指登船、在船上；组合让人联想到网站的驾驶舱，也呼应独立开发者出海。Board 还提供了看板的联想。品牌可以覆盖统计、SEO、运维和 agent 工作流。

## 对外描述

中文：**开源的网站运营驾驶舱，在本地用数据和 agent 管好你的站。**

英文：**Open-source website operations, on your machine, with your agent.**

首页标题候选：`SiteAboard — Local Website Analytics, SEO & Agent Workflows`。标题中的能力在对应功能交付后使用；早期仓库应明确标注静态演示与规划能力。

## 命名筛选

2026-10-24 对名称做精确词组与产品搜索。SiteAboard 未发现明显同名同类产品；这是检索结论，不代表域名、npm 包名或商标已核验、可注册。

SiteOps 过于通用，[SiteSail](https://www.sitesail.com/) 已用于网站与营销服务，[SiteHelm](https://getsitehelm.com/) 已用于网站监控；不采用这些容易混淆的名称。SiteAhoy、Saillytics 是本轮备用方向，最终选择 SiteAboard。

## 搜索与内容

品牌名负责识别，文档回答具体任务；不把名字包含关键词当成排名保证。[Google SEO 入门说明](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)明确区分清晰内容与仅在域名中放关键词的作用。

早期内容围绕：如何本地管理多个网站、埋点没有数据怎么查、GSC 有曝光没有点击、如何用 agent 做网站复盘、发布后如何观察转化变化。内容给出输入、步骤和验收，功能交付前不编造教程或用户案例。

当前使用 GitHub Pages 展示静态演示，文档维护在仓库。首版图标采用原创帆船 SVG；独立官网和域名留待后续阶段。
