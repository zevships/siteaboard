# SiteAboard 实施路线

阶段按验收推进，不承诺尚未测量的工期。当前完成 M0、F0 与 F1 只读数据视图；M1 的采集写入与 CLI 闭环尚未完成。

## M0 项目定义

- [x] 名称确定为 SiteAboard · 站舱。
- [x] 独立目录，从空目录建立，不带入历史和私人数据。
- [x] 写明产品范围、技术架构与分阶段验收。
- [x] 采用 MIT 许可；设置本地数据与凭证忽略规则。

## F0 公开前端基础

- [x] 初始化锁定依赖的 React + Vite + TanStack Router 静态应用。
- [x] 总览、站点、搜索、动态、连接、指南独立页面与懒加载。
- [x] 三种主题、浅深色和跟随系统、中英文、响应式导航。
- [x] 一致的合成数据、7/30 天切换、图表和可读数据表。
- [x] 双语 README、agent 规范、目录接入指南、GitHub Pages 自动部署配置。
- [x] 类型、契约、公开产物与桌面/手机浏览器检查。

这是可预览的 UI 基础，不代表 M1 本地服务与 CLI 已完成。

## F1 运营界面与只读数据替换

- [x] 恢复紧凑横向布局、按站点数据卡与旧版交互动效，增加主题质感层。
- [x] 七个站点分析页签、六档日期、图表提示、筛选和展开明细。
- [x] 统一版本化数据契约、合成数据与只读本地 SQLite 快照。
- [x] 公共/本地构建隔离、来源与会话校验、缺失数据不回退演示。
- [x] 原始样式隔离对照、三种宽度黑盒与数据/访问边界白盒检查。

未迁移旧工具的私人社交、设备、媒体与个人模块。搜索市场潜力/实时 SERP、
细粒度运行采集、写入式问题管理等在有真实连接器和用例后继续扩展；当前
公开按钮不伪装成真实同步、发布或写入操作。

## M1 无账号也能体验的纵向切片

先交付总览和站点两个页面、一份合成数据、一条相同结果的 CLI 查询。

- 在已完成的静态前端上增加本地服务；评估 TanStack Start 并锁定服务依赖。
- 定义 Site、MetricResult、DataQuality 和 fixture connector；建立 SQLite 初始迁移。
- 实现一个本地服务、writer 锁、访问握手、`serve/doctor/sites list/metrics summary`。
- 普通浏览和同步不调用 LLM；demo 使用独立数据目录。
- 服务启动生命周期支持开发与生产构建，调度不依赖 Vite dev plugin。

验收：全新目录无需其他仓库、账号或密钥能构建并启动；同一查询在 UI/CLI 一致；空数据、部分数据、失败可辨；第二个 writer 被拒绝；重启保留数据。

## M2 真实站点接入与第一次运营复盘

- 实现 GSC 与一个真实流量连接器，优先复用可独立提取的既有适配。
- 完成凭证设置、权限检查、游标、覆盖范围、重试、限流与撤销路径。
- 将搜索、连接和动态页面接入真实查询，增加任务状态与最小问题/改动/复查记录。
- 提供接入和复盘 skills；文档只引用已实现 CLI 命令。

验收：用户自己接入一个站点；断网/过期授权不会显示为零；重复拉取不重复计数；复盘能追到数据和时间范围；移除连接后不继续拉取。

这里先验证统一运营流程，不把付费统计服务作为永久前置条件。

## M3 自有埋点路径

- 明确事件字典、去重与测试流量标识。
- 选一种网站运行环境交付事件接收模板及部署指导。
- 实现本地拉取连接器、检查埋点 skill、最小漏斗能力。
- 界面展示接收端状态和数据保留/费用边界。

验收：测试事件从网站到本地可追踪，生产与测试隔离；无权限无法导出数据；漏斗口径可解释；本机离线后能补拉保留期内数据。

M3 通过后才可以宣称提供无需购买统计 SaaS 的自有采集方案；云端运行费用另列。

## M4 小范围公开测试与文档站

- 用公开前检查逐文件确认来源、许可、依赖和隐私；仓库本身不带内部调查资料。
- 补齐实际安装、故障排查、卸载、备份恢复与升级文档。
- 邀请 5–10 位开发者试用，收集首次接入和一周复用反馈。
- 确定支持平台，按实测写入矩阵。
- 在公开仓库和合成演示基础上，根据真实问题制作文档站，再发布可安装软件包。

验收：用户不用维护者改源码即可完成一次有证据的改进；公开资源不含真实站点截图、内部账号、密钥或默认遥测。

## 迁移顺序

| 既有资产类别                 | 放入新项目               | 迁移条件                                   |
| ---------------------------- | ------------------------ | ------------------------------------------ |
| 时间、期间和指标纯函数       | core/domain              | 定义通用，保留边界测试                     |
| 站点图表与表格               | apps/admin               | props 与数据层解耦，替换产品文案和私有链接 |
| 查询、SQLite 与采集          | core/storage、connectors | 不依赖旁边仓库；配置和凭证有接口           |
| 调度器                       | core/runtime             | 可从正式服务启动；单写者和中断恢复可验证   |
| 接入、复盘、SEO 指导         | skills                   | 只依赖公开 CLI 和参考文档                  |
| 社媒、影视、设备、个人事实库 | 不迁入                   | 不在首版产品边界内                         |

## 留待实现验证的决策

首个真实流量连接器、GSC 的分发授权体验、跨平台凭证库实现、网站接收端部署适配器、文档生成器。每项在对应里程碑落实，不阻塞 M1 的无凭证闭环。
